Install on Android

Use Chrome on an Android phone. This file will not install on an iPhone, and it will not install from WhatsApp or Instagram.

Download why-engineering-1.3.apk

  1. If this page is inside another app, open the menu and choose Open in Chrome.
  2. Tap the blue button. If Chrome says the file may be harmful, tap Download anyway.
  3. When the download finishes, tap Open. The name must be why-engineering-1.3.apk.
  4. If the phone says Chrome cannot install apps, tap Settings, turn on Allow from this source, then open the file again.
  5. Install, then open Why Engineering. The phone needs a network connection.

Delete any older download that does not end in .apk. That file will not open.
