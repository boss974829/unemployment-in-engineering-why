# AI Tech Updates — Signal / Shift

A responsive technology intelligence site covering recent developments, influential technology leaders, companies shaping the future, and changing job tasks. The site includes a live news feed and can be installed as a Progressive Web App on supported browsers.

## Publish the website

1. The site is published at `https://boss974829.github.io/unemployment-in-engineering-why/ai-tech-updates/` by the repository's GitHub Pages workflow.

## Android APK

The Android app is a small WebView wrapper around the published site. Push a tag such as `aitech-v1.0.0` to build an installable APK and attach it to a GitHub Release. The APK requires an internet connection because it opens the hosted site.

## Data and attribution

News is fetched from a public RSS-to-JSON service and headlines link to their publishers. Availability and refresh depend on the third-party feed service. The site is an editorial guide, not financial or career advice.
